# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue or pull request for them.

Include the mod, what an attacker could do, and the steps to reproduce. You'll get a reply within a week.

## What counts

Anything in this repository that could:

- run a command or code the user didn't intend,
- send local data (files, processes, environment, credentials) off the machine or to the model,
- show a secret that should have been masked,
- or let a pull request change what an installed mod does without review.

## Supported versions

Only the latest commit on `main` is supported.
